# Запуск редактора карт

## Рекомендуемый способ (локальный сервер)

1. Откройте терминал.
2. Перейдите в папку `Create Image`.
3. Запустите сервер:

```bash
python3 -m http.server 8000
```

4. Откройте в браузере: <http://localhost:8000/>
5. Чтобы остановить сервер, вернитесь в терминал и нажмите `Ctrl+C`.

Сервер нужен потому, что редактор загружает `assets/data.json`; при открытии `index.html` двойным кликом через `file://` браузер может заблокировать этот запрос.

## Обновление списка изображений

После того как в `Create Image/1` появились новые папки или изображения:

1. Откройте редактор.
2. Нажмите **«Обновить каталог»**.
3. В окне выбора папки выберите папку `Create Image` целиком (либо папку `1`, если нужны только коллекции).
4. Редактор просканирует выбранные изображения и добавит их в окно выбора карт.
5. В поле **«Изображение»** нажмите **«Выбрать изображение»** и выберите новую папку.

Браузер не разрешает веб-странице молча следить за изменениями обычной папки, поэтому обновление запускается этой кнопкой. Новые выбранные файлы доступны в текущем сеансе редактора.

## Работа с картами

- **Галерея** — просмотр и поиск карт.
- **Существо / Заклинание** — создание и редактирование.
- **Скачать JSON** — экспорт резервной копии карт.
- **Загрузить JSON** — импорт сохранённой коллекции.

Данные карт сохраняются в `localStorage` браузера. Для переноса на другой компьютер используйте экспорт JSON.

## Важно

Не удаляйте папку `assets`: в ней находятся логика редактора, стили, каталог изображений и демонстрационные данные.
