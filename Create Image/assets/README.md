# Мастерская карт

Откройте корневой `index.html` в современном браузере. Интернет, аккаунт и сборка не требуются. Сохраняйте рядом папки `assets` и `1`: JSON содержит пути к изображениям, а не сами изображения.

## Работа
1. Откройте «Существо» или «Заклинание», заполните поля и выберите изображение из папки.
2. Нажмите «Сохранить». Предпросмотр обновляется при изменении полей.
3. В «Галерее» используйте поиск и фильтры; кнопки под картой позволяют изменить, отключить, скопировать или удалить карту.
4. Перед переносом или резервным копированием нажмите «Скачать JSON». Несохранённый черновик в экспорт не входит.
5. «Загрузить JSON» восстанавливает коллекцию; при наличии карт можно заменить их или добавить.

Сохранённые карты остаются в localStorage этого браузера. Это не замена резервной копии: скачивайте JSON после работы. «Авто» определяет устройство, «ПК» и «Мобильный» задают вид вручную. Это адаптивный сайт, не отдельный APK.

При открытии двойным кликом галерея изначально пустая. Примеры можно загрузить вручную из `assets/data.json`. Через HTTP примеры загружаются автоматически, если коллекция ещё не сохранена.

Для просмотра через локальный сервер из корня проекта:
```
python -m http.server 8000 --bind 127.0.0.1
```
Адрес: http://127.0.0.1:8000 . Для доступа с телефона нужен отдельный доступный ему хостинг либо сервер в локальной сети.

## Проверки
```
node --check assets/app.js
node --check assets/catalog.js
node assets/check.cjs
```
Браузерный интеграционный тест (отдельный чистый профиль Edge, пользовательские данные не меняет):
```
npm install --prefix .sharrowkin/qa --no-audit --no-fund playwright
node assets/browser-test.cjs http://127.0.0.1:8000
```

Каталог `assets/catalog.js` содержит 166 изображений в пяти группах. После добавления новых файлов обновите каталог: браузер не может сам перечислить соседние папки. Формат экспорта: `{ version: 1, minions: [...], spells: [...] }`.
