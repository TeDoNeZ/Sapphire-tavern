# Отчёт миграции существ и изображений

Дата: 2026-11-01

## Что сделано

- Источником новых объектов выбран `../archive/legacy-assets`, а не `HS v2/assets/archive`.
- В рабочий каталог импортированы 120 карт племён `beast`, `mech`, `naga` и `pirate`.
- PNG-файлы подключены через явные поля `image` в `Существа.json` и `src/cards.js`.
- Старый каталог из 238 записей сохранён в `archive/legacy-cards/Существа.json`; исходный модуль сохранён рядом.
- Старые записи доступны только через помеченный `legacyCards` compatibility-слой и исключены из пула таверны (`removed: true`).
- Пул архетипов игры синхронизирован с четырьмя импортированными племенами.
- Сохранены существующий HTML/CSS и адаптивная раскладка.
- Тесты дополнены проверками источника, локального изображения, масштабирования и скрытого архива.

## Известные проблемы

- Для 58 объектов из `mech`/`naga` в исходном наборе нет характеристик и текста карты. Они помечены `missingData: true` и временно используют 1/1 с поясняющим текстом.
- Две карты из `beasts/main.json` не имеют PNG: `Дух Перерождения` и `Дух Стаи`. Они оставлены в активном каталоге с намеренно несуществующими ссылками `image`, поэтому браузер покажет ошибку загрузки изображения. Это ожидаемая отметка проблемы, а не тихое удаление карт.
- У импортированных карт нет старых effect-id; для них используется общий безопасный режим. Старые обработчики сохранены только для скрытого compatibility-слоя.

## Проверка

- `npm.cmd test`: 34/34 теста проходят.
- `npm.cmd run test:browser`: не выполнен в текущем окружении — Playwright не нашёл установленный Chromium (`npx playwright install` потребуется отдельно). UI не перерабатывался, структурные тесты проходят.
