# Рабочие изображения

**Известная проблема:** [u28.png](<assets/cards/u28.png>) имеет размер 0 байт. Этот файл не изменялся при упорядочивании. Его нужно отдельно заменить настоящей иллюстрацией; старый SVG сохранён в [архиве](<fresh/assets/cards/u28.svg>).

Игра использует только локальные ресурсы из [assets](<assets/>).

- [Карты и токены](<assets/cards/>): 30 PNG нежити и 55 SVG остальных существ и токенов. Пути заданы в [каталоге](<src/cards.js>), включая изображения временно отключённых карт.
- [Уровни таверны](<assets/tiers/>): 6 PNG.
- [Типы целей заклинаний](<assets/spells/>): 3 PNG.
- [Значки атаки и здоровья](<assets/ui/>): 2 PNG, используемые в [стилях](<styles/styles.css>).
- [Иллюстрация заклинания](<assets/spell.svg>).

Пути изображений карточек разрешаются относительно HTML-страницы, а URL в CSS — относительно самой таблицы стилей. Поэтому при перемещении исходников ссылки карточек оставлены прежними, а CSS-ссылки обновлены.

Старые SVG нежити, неиспользуемые иконки и исходная HTML-вырезка интерфейса перенесены в [fresh/assets](<fresh/assets/>). Старый справочник сохранён в [архиве](<fresh/docs/ASSETS.md>) без изменений.

`npm run assets` создаёт справочные заглушки в отдельной папке `fresh/generated-assets`, **не перезаписывая рабочие изображения**. Для игры запускать генератор не требуется.
