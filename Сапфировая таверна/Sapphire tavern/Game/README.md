# Сапфировая таверна

Мобильная одиночная браузерная игра по мотивам авто-баттлеров: игрок собирает армию против бесконечных случайных ботов.

## Запуск

```bash
cd "/root/Documents/HS v2"
npm start
```

Откройте `http://localhost:4173` на компьютере или откройте адрес компьютера в браузере телефона в той же Wi‑Fi сети.

Порт можно изменить:

```bash
PORT=8080 npm start
```

## Управление

- Коснитесь карты, затем выберите действие в панели описания.
- На телефоне удерживайте карту около 220 мс и перетащите её: магазин → рука/поле, рука → поле, поле → продажа.
- Купить — 3 золота; продать — 1; обновить таверну — 1; заморозить — бесплатно.
- Поле — 8 мест, рука — 15 карт.
- Три одинаковые карты дают золотую версию ×2; три золотые — сапфировую ×4. После триплета появляется раскопка.
- Кнопка «В бой» запускает автоматический бой без таймера. Можно ускорить или пропустить анимацию.
- Раунды бесконечны. После поражения при нулевом здоровье здоровье возвращается к 40, а армия и прогресс сохраняются.

## Проверки

```bash
npm test
npm run test:browser
```

Модульные тесты находятся в [tests](<tests/>). Они проверяют движок, экономику, заклинания, журнал и целостность путей к модулям и изображениям.

Браузерная проверка — [browser-check.mjs](<tests/browser-check.mjs>). Она требует запущенного `npm start` и установленного Chromium для Playwright. Снимки сохраняются в `artifacts/browser`. В текущем контейнере ранее наблюдалось падение Chromium; прохождение модульных и HTTP-проверок не означает, что визуальная браузерная проверка тоже выполнена.

## Изображения

Рабочие изображения перечислены в [справочнике ассетов](<docs/ASSETS.md>). Используются PNG и SVG; игра не загружает картинки из внешней сети.

Генератор [generate-assets.js](<tools/generate-assets.js>) запускается командой `npm run assets`. Он сохраняет справочные SVG в `fresh/generated-assets` и не меняет рабочие изображения.

## Структура проекта

- [src](<src/>) — интерфейс и игровые модули.
- [styles](<styles/>) — таблицы стилей.
- [assets](<assets/>) — только подключённые изображения игры, включая изображения отключённых карт.
- [tests](<tests/>) — модульные тесты и браузерная проверка.
- [tools](<tools/>) — вспомогательные инструменты.
- [docs](<docs/>) — документация, исходное описание игры и [журнал переносов](<docs/FILE-MOVES.json>).
- [fresh](<fresh/>) — неиспользуемые и исторические материалы для ручного разбора. [Описание архива](<fresh/README.md>) объясняет причины переноса. Ничего окончательно не удалено.

В корне оставлены [HTML-страница](<index.html>), [сервер](<server.js>), [настройки npm](<package.json>), [lock-файл](<package-lock.json>) и этот документ. Зависимости в `node_modules` не перемещались: они нужны для работы инструментов.

Запуск остаётся прежним: `npm start`. Установка зависимостей на другой машине: `npm ci`. Сохранения игры в браузере и ключ localStorage не менялись.
